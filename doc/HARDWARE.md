## 3. 开发板核对结论（来自商家原理图和产品图）

- 模组为 ESP32-S3-WROOM-1，N16R8：16MB Flash（四线）+ 8MB PSRAM（八线）。
- **两个 Type-C 口**：一个经 CH343 串口芯片（UART0，用于烧录、日志、供电），一个是原生 USB（GPIO19/20）。Windows 需安装 CH343 驱动。
- **自动下载电路**：串口芯片通过 DTR/RTS 控制 EN 和 GPIO0，所以 **不要在 GPIO0 和 EN 上外接电路**。
- **板载 RGB 灯**：WS2812，数据线接 **GPIO48**，该脚不要另作他用。
- BOOT 键接 GPIO0，RST 键接 EN。
- 3.3V 引脚只有 **2 个**，5V 和 GND 有多个。本方案中 OLED 和麦克风各占一个 3.3V，刚好用完；按键用内部上拉、接 GND，不需要 3.3V。
- 商家说明里写“带天线和不带天线因生产批次不同随机发货”。如果收到的是外接天线接口版本，不接天线时蓝牙和 Wi‑Fi 距离会很差，**建议补一根 2.4GHz IPEX 天线备用**，或下单前向商家确认发板载天线版。

## 4. 引脚分配（草案，到货后对照开发板丝印核对）

| 功能 | GPIO | 说明 |
| --- | --- | --- |
| OLED SDA | GPIO8 | I2C 数据；模块原理图标注从机地址 0x78（8 位），即 7 位地址 0x3C；D/C# 接 VCC 时为 0x3D |
| OLED SCL | GPIO9 | I2C 时钟 |
| 收工键 / 触摸 SIG | GPIO4 | 按键另一端接 GND，固件启用内部上拉，按下为低电平；改用 TTP223 触摸时 SIG 接此脚并拔掉按键线（二者互斥），极性相反由固件处理 |
| 自定义键 | GPIO5 | 同上，也可作按住说话键 |
| 备用按键 1 / 2 | GPIO6 / GPIO7 | 可选 |
| 触摸区·左 SIG | GPIO10 | TTP223 触摸模块，触摸=高电平（与按键低有效相反），固件按高有效读 |
| 触摸区·右 SIG | GPIO11 | 预留第二块触摸模块 |
| 麦克风 SCK（BCLK） | GPIO1 | I2S 位时钟 |
| 麦克风 WS | GPIO2 | I2S 帧时钟 |
| 麦克风 SD | GPIO42 | I2S 数据 |
| 麦克风 L/R | GND | 固定为左声道，固件配置左声道 |
| 外接灯带 DATA | GPIO18 | 预留，经电平转换接灯带 |
| 旋钮 A / B / 按压 | GPIO15 / GPIO16 / GPIO17 | 预留，EC11：CLK=A→15、DT=B→16、SW→17 |
| 板载 RGB 灯 | GPIO48 | 已在板上 |

**避免使用的引脚：**

- GPIO0：BOOT 和自动下载。
- GPIO3、GPIO45、GPIO46：启动策略引脚。
- GPIO19、GPIO20：原生 USB。
- GPIO43、GPIO44（板上丝印 TX/RX）：串口烧录与日志。
- GPIO35–37：N16R8 的八线 PSRAM 占用，虽然被引出，但不可用。
- GPIO48：板载 RGB 灯。

## 7. 按键接线

使用 4 位独立按键模块（5 针排针）。该模块没有商家资料，下面按最常见的 `GND + K1–K4` 定义设计，**到货后必须确认丝印，并用万用表蜂鸣档测按下时对应针脚与 GND 是否导通**。

| 按键模块 | 接开发板 |
| --- | --- |
| GND | GND |
| K1（收工键） | GPIO4 |
| K2（自定义键） | GPIO5 |
| K3（备用） | GPIO6 |
| K4（备用） | GPIO7 |

固件用内部上拉，按下读到低电平；去抖和长按在软件里处理。若模块带 VCC 引脚，需要接 3.3V，而开发板只有 2 个 3.3V 引脚，已被 OLED 和麦克风占用，此时用面包板分电（需要公对母杜邦线）。

## 7.1 触摸模块接线（TTP223 电容触摸模块，2026-11-03 定案）

面包板方案后新增的模块。**第一块 SIG 接 GPIO4**（占用原 K1 收工键脚）：按键对地短路、传感器主动输出，**同一脚只能接一个**——插 SIG 前必须先拔掉 K1 按键的跳线。它在固件里扮演收工键还是触摸区由固件配置决定，接线不变。第二块触摸模块预留 GPIO10/11。

| 触摸模块引脚 | 接法 |
| --- | --- |
| SIG | GPIO4（第一块）；GPIO10/11（后续模块预留） |
| VCC | 3V3 电源轨（模块允许 2–5.5V） |
| GND | GND 电源轨 |
| 其余针脚 | 空着 |

注意极性与按键相反：TTP223 默认输出为"触摸=高电平、未触=低电平"（AHLB 焊盘不焊），固件按高有效读取并做去抖，不要给它开上拉当按键用。若将来想零改固件，可把模块 AHLB 焊盘短接改为低有效输出，再直接顶替按键脚。

## 7.2 旋钮接线（EC11 编码器模块，预留）

到货模块实测丝印（2026-11-03，5 针单排，按排列顺序）：`GND S1 S2 KEY 5V`。

| 旋钮模块引脚（实际丝印） | 接法 |
| --- | --- |
| GND | GND 电源轨 |
| S1（A 相） | GPIO15 |
| S2（B 相） | GPIO16 |
| KEY（按压） | GPIO17 |
| 5V（板载上拉电阻供电） | **3V3 电源轨**：这一路只给上拉电阻供电，接 3V3 则信号高电平为 3.3V；**不要接开发板 5V 针**，否则 GPIO 吃到 5V 有烧脚风险。不接则靠固件内部上拉，功能不受影响 |

通用命名对照：S1=CLK=A、S2=DT=B、KEY=SW、5V≈VCC。固件尚未实现旋钮读取，接线仅作预留验证。

## 8. RGB 灯带（预留，可后买）

- 先用板载 WS2812（GPIO48）验证灯效，不必急着外接灯带。
- 外接 WS2812B 时：GPIO18 → 74AHCT125/74AHCT1G125 电平转换 → 330Ω 串联电阻 → DIN；灯带 5V 与 GND 间并联 470–1000µF 电容；5V 来自开发板 5V 引脚，与开发板共地。
- 每颗灯全亮约 60mA，灯数多时需限制亮度或外接 5V 电源。

## 8.1 麦克风数据手册核对（INMP441 芯片手册）

- 供电 1.8–3.3V（绝对最大 3.63V），只能接 3.3V。
- 接口为 I2S，24 位二进制补码，每帧 64 个 SCK（每声道 32 个）。
- SCK 频率 0.5–3.2MHz；采样率 = SCK ÷ 64，16kHz 对应约 1.024MHz，在范围内。
- L/R 接低为左声道，接高为右声道；L/R 不能悬空。
- 上电后约 85ms 内输出为 0。
- 不要在 VDD 未供电时向 SCK/WS 送时钟。
- 固件建议按 32 位读取并右移，不要直接用 16 位例程。
- 注意：项目文件夹里的手册是 INMP441 芯片手册，购物车里的是商家的国产芯片版本，实际表现需实测。

## 9. 语音上传设计要点

- 原始 16kHz/16bit 单声道约 256kbps，BLE 实际吞吐往往跟不上实时传输。
- 采用“按住说话、先录后传”：录音缓存到 PSRAM，松开后分块经 BLE 传给手机；可叠加 ADPCM 压缩；必要时改走 Wi‑Fi。无需额外硬件。
- 先只验证采集和音量，再做上传。

### 9.1 Wi‑Fi 与 MQTT 云连接

- ESP32-S3 内置 2.4GHz Wi‑Fi 和 BLE，不需要外加 Wi‑Fi 模块；不支持 5GHz。
- 设备可作为 MQTT 客户端（TLS）连接 MQTT 服务器，发布状态、订阅指令；App 也作为 MQTT 客户端订阅状态，可满足 PRD 中的多设备共享看板。
- 需要自己部署或租用 MQTT 服务（如 EMQX、Mosquitto 或云厂商的物联网服务），并配置每设备认证、按用户的主题权限（ACL）、遗嘱消息（用于离线判定）。
- 联网后可用 NTP 校时，缓解“无实时时钟、断电丢时间”的问题。
- Wi‑Fi 首次配网可通过 BLE 或设备热点完成；办公室常见的需登录认证的 Wi‑Fi 或企业 Wi‑Fi 可能连不上，需保留 BLE 和手机热点作为备用。
- iOS App 在后台通常无法长期保持 MQTT 连接，后台提醒要靠推送服务。
- MQTT 适合状态与指令，不适合直接传实时音频；语音建议用 HTTP/WebSocket 分块上传，或先录后传。
- 隐私：默认不上传状态历史，只在用户开启共享时发布当前状态，并使用 TLS 和最小数据字段。

## 11. 开发顺序

1. 安装 CH343 驱动、Arduino-ESP32 或 PlatformIO，烧录示例，确认串口日志和下载正常。
2. 驱动板载 RGB 灯，验证 GPIO48。
3. 点亮 OLED，显示状态大字（可用 U8g2 等库），确认 I2C 地址和引脚顺序。
4. 接按键，实现短按切换状态、长按收工。
5. 用 BLE 通过手机工具读写状态，再设计设备与 App 的协议。
6. 把状态变化记录写入闪存，通过 BLE 读取。
7. 接 I2S 麦克风，读取并观察音量。
8. 做你自己的 App、计划表、语音上传。

## 14. 首次实测记录（2026-11-01）

**已验证：**

- 开发板丝印与 §3 排针表完全一致；板载 RGB（GPIO48）闪烁验证通过（`firmware/verify`）。
